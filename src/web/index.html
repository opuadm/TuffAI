TuffAI

API documentation

OpenAI-compatible chat completions, running locally. All /v1 endpoints require authentication.

Base URL

Authentication

Programmatic access requires an API key created in the Admin panel. Send it as a Bearer token:

Authorization: Bearer tk_...

The browser chat is reserved for signed-in admins. Admin sessions are also accepted as Bearer tokens on /v1 endpoints.

Endpoints

GET/v1/models

Lists the TuffAI models compiled into this binary. Requires an API key or admin session.

POST/v1/chat/completions

Creates a chat completion or an SSE stream. Requires an API key or admin session.

Example request

curl http://localhost:18298/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer tk_YOUR_KEY' \
  -d '{
    "model": "TuffAI-v3",
    "messages": [
      {"role": "system", "content": "Answer briefly."},
      {"role": "user", "content": "Why is the sky blue?"}
    ],
    "temperature": 1.15,
    "reasoning_effort": "Medium",
    "stream": true
  }'

Request parameters

FieldTypeDescription
modelstringModel ID returned by /v1/models.
messagesarraySystem, developer, user, assistant, and tool messages.
temperaturenumberSampling temperature. Uses the selected model’s default when omitted.
top_pnumberNucleus sampling from 0 to 1.
frequency_penaltynumberReduces repeated token frequency.
presence_penaltynumberAdjusts preference for already-present tokens.
max_tokensintegerLimits generated output.
streambooleanReturns Server-Sent Events when true.
noisenumberTuffAI sampling noise override.
repetition_penaltynumberTuffAI repetition penalty override.
reasoning_effortstringNone, Low, Medium, High, or Max on supported models.
web_searchbooleanEnables autonomous search for this request. May increase latency.

Thinking and streaming

Non-streaming responses include model thinking in choices[0].message.reasoning_content. Streaming responses emit it as choices[0].delta.reasoning_content before answer content when the model produces thoughts.
